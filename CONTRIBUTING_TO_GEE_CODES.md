# Contributing to Google Earth Engine Interdisciplinary Research 

Thank you for your interest in contributing to this repository which aims to broaden our understanding of the blue planet applying satellite data, statistical analysis and machine learning algorithms !

## Project Overview

This repository contains Google Earth Engine workflows for environmental research, remote sensing, water resources management and geospatial data analysis.

## How you can contribute:

1. Fork the repository.
2. Create a branch for your contribution.
3. Add or improve Python scripts or documentation.
4. Test your changes.
5. Submit a pull request describing your changes.

## Research Reproducibility

Please document data sources, requirements, methods, and software dependencies when contributing to the repository.

## Questions

Feel free to open a GitHub issue to discuss potential improvements or research collaborations.
